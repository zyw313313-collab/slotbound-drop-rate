调节 Slotbound 爆率

在运行中的游戏里调节五档稀有度概率。仅供单机使用，工具本身不修改游戏文件或存档。

工具 v1.2.1 Windows 10 / 11 x64 中 / EN 双语
下载 Windows 版 ZIP 一键安装脚本 查看源码

支持的游戏版本

工具 v1.2.1 随附的配置仅支持写入 Windows x64 的 Steam 版 Slotbound v1.0.4（构建 26899345），不再支持旧构建的写入。

它能做什么

调节五档爆率

普通 / 高级 / 稀有 / 传说 / 棱彩。五项百分比之和必须为 100%。

读取、应用、恢复

查看游戏当前的数值，应用并验证新数值，或还原修改前的爆率。

只改内存

重启游戏会清除爆率修改。游戏正常存档可能保留已经获得的结果。

安装

完整解压 SlotboundDropRate.zip 后运行 EXE，保留 EXE、INI 和 update-compatibility.bat 在同一目录。也可使用一键安装脚本，文件会安装到 %LOCALAPPDATA%\SlotboundDropRate，并创建桌面快捷方式。需要 .NET Framework 4.x（Windows 10/11 自带）。

如果后续游戏更新只需更换配置，关闭工具后，可从发布页下载独立的 slotbound-compatibility.ini，手动替换工具 EXE 同目录的文件，再打开工具。工具不会联网自动获取配置。

用法

  1. 启动游戏，进入一局并等待加载完成，再运行本工具。
  2. 点击 读取当前爆率，查看游戏中的五档实际数值。
  3. 设置五项百分比，使总和为 100%，再点击 应用一次。
  4. 需要还原时，点击 恢复原始爆率。

Steam 小更新后无法应用或恢复爆率？查看本地兼容助手的用法。

建议先备份存档目录 %APPDATA%\slotbound_full。

常见问题

无法读取当前爆率？

确认游戏已加载完毕；若游戏刚更新，请重启游戏，再点击“读取当前爆率”。如果能读却不能应用或恢复，请看下面的 Steam 小更新说明。

为什么只能读取，不能应用或恢复？

游戏 EXE 和 Lua 运行库匹配时，未知 Steam 构建或不匹配的 Slotbound.dat 仍可尝试只读诊断。配置缺失、无效或不匹配时绝不会启用写入。游戏 EXE 或 Lua 运行库发生变化时，连只读诊断也会停止。

Steam 小更新后，怎么试用本地兼容助手？

v1.2.1 起，解压或安装发布包后，update-compatibility.bat 位于工具 EXE 和 INI 旁。通过一键安装的玩家可将 %LOCALAPPDATA%\SlotboundDropRate 粘贴到资源管理器地址栏。

重启已更新的游戏，进入一局可丢弃的单机测试局并等待加载完成。先关闭旧的工具窗口，再双击启动器。助手只读扫描运行中的游戏，自动获取 Steam Build ID 和 Slotbound.dat 的 SHA-256，并提示你按 x.y.z 格式输入实际的游戏版本号。通过检查后，它另存为 slotbound-compatibility.candidate.ini。

“替换”确认默认选 否，不会动现用配置。明确选 是 后，助手先在同目录将现用配置备份为 slotbound-compatibility.backup-*.ini，再安装候选配置；若原本没有现用配置，则不创建备份。

只读扫描通过不等于实机玩法已经验证。重新打开工具，在这局单机测试中实际触发普通稀有度抽取，并验证应用和恢复原始爆率均正常。这是本地实验配置，不会自动发布。

要回退，先关闭工具，用备份替换现用的 slotbound-compatibility.ini，或重新安装官方发布包。如果游戏 EXE、Lua 运行库或爆率表有变化，助手不会生成候选配置，请等待工具更新。

设为 100% 后，每次转动都会出现该稀有度吗？

普通稀有度抽取需要转出匹配的符号。剧情或其他脚本指定的结果可能不遵循这些概率。受控实机测试中，棱彩设为 100% 时出现了一个棱彩长矛单位，传说设为 100% 时出现了两个传说骷髅法师。

自己编译

仓库里是完整的 C# 源码，只依赖 Windows 自带的 .NET Framework：

powershell -ExecutionPolicy Bypass -File build.ps1 → 生成 dist\SlotboundDropRate.exe、dist\slotbound-compatibility.ini、dist\update-compatibility.bat 和包含这三个文件的 dist\SlotboundDropRate.zip。安装此 ZIP 时，启动器与 EXE 和 INI 安装在同一目录。
