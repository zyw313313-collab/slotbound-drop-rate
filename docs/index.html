调节 Slotbound 爆率

在运行中的游戏里调节五档稀有度概率。仅供单机使用，工具本身不修改游戏文件或存档。

v1.1.2 Windows 10 / 11 x64 中 / EN 双语
下载 Windows 版 一键安装脚本 查看源码

支持的游戏版本

支持 Windows x64 的 Steam 版 Slotbound v1.0.2（构建 26791687）和 v1.0.3（构建 26848798）。

它能做什么

调节五档爆率

普通 / 高级 / 稀有 / 传说 / 棱彩。五项百分比之和必须为 100%。

读取、应用、恢复

查看游戏当前的数值，应用并验证新数值，或还原修改前的爆率。

只改内存

重启游戏会清除爆率修改。游戏正常存档可能保留已经获得的结果。

安装

下载并运行 SlotboundDropRate.exe，也可使用一键安装脚本创建桌面快捷方式。需要 .NET Framework 4.x（Windows 10/11 自带）。

用法

  1. 启动游戏，进入一局并等待加载完成，再运行本工具。
  2. 点击 读取当前爆率，查看游戏中的五档实际数值。
  3. 设置五项百分比，使总和为 100%，再点击 应用一次。
  4. 需要还原时，点击 恢复原始爆率。

建议先备份存档目录 %APPDATA%\slotbound_full。

常见问题

无法读取当前爆率？

确认游戏已加载完毕，并且使用受支持的 Steam 构建，然后再次点击“读取当前爆率”。

设为 100% 后，每次转动都会出现该稀有度吗？

普通稀有度抽取需要转出匹配的符号。剧情或其他脚本指定的结果可能不遵循这些概率。受控实机测试中，棱彩设为 100% 时出现了一个棱彩长矛单位，传说设为 100% 时出现了两个传说骷髅法师。

自己编译

仓库里是完整的 C# 源码，只依赖 Windows 自带的 .NET Framework：

powershell -ExecutionPolicy Bypass -File build.ps1 → 生成 dist\SlotboundDropRate.exe
