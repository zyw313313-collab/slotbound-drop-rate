Slotbound（转运军团）单机爆率调节工具。运行时改写本局稀有度权重，不改游戏文件、不改存档、不碰联机，重启游戏即恢复原版。界面中/英双语，自动跟随系统语言，也可右上角切换。

它能做什么

五个稀有度随便调

普通 / 高级 / 稀有 / 传说 / 棱彩，填百分比，点“应用一次”。默认值就是你存档里的真实爆率 80 / 15 / 4.5 / 0.4 / 0.1。

自动补丁

勾上“自动”，每秒钟补一次。新开一局、游戏重新生成爆率时也会自动改写，不用反复点。

只改内存

游戏的数据包 Slotbound.dat 是加密的，改文件不可行。本工具只写运行中进程的内存，关掉游戏就恢复原样。

安装 / 使用

  1. 启动游戏，进入一局，先拉一次杆（让这一局的爆率数据生成）。
  2. 运行本工具。首次运行会弹 UAC，点“是”（游戏由 Steam 启动，通常也是管理员权限，必须同级才能读写）。
  3. 工具会自动连接 Slotbound.exe，底部显示“已连接 Slotbound (PID …)”。
  4. 填五个百分比，点 应用一次；底部会显示匹配/改写了几处。
  5. 想对新开一局也生效，勾上 自动。想还原就把数字改回默认再点应用，或直接重启游戏。

建议先备份存档目录 %APPDATA%\slotbound_full。本工具不写存档，但改爆率后游戏自己的存档行为不变，备份总是更稳。

常见问题

显示“未找到 Slotbound.exe” / “无法打开进程”

先用管理员身份运行本工具（右键 → 以管理员身份运行），并确认游戏已经进到一局里。Steam 以管理员启动时，游戏进程也是高权限，普通权限的工具读不到。

点了应用，但底部是“匹配 0 处”

说明这一局还没有生成可改的爆率串：先拉一次杆再点；或者直接勾“自动”。仍然为 0 的话，把界面截图发到 GitHub Issues。

改了之后拉杆没变化？

个别版本会把爆率在开局时算成数字缓存。勾上“同时改数值表（实验）”再试；还不行请在 Issues 里反馈游戏版本号。

会被封号吗？

这是纯单机游戏，没有联机对战、排行榜和交易，工具也只读写自己的进程内存，不碰 Steam 和正版验证。风险由使用者自行承担。

支持 Mac / Linux / 手机版吗？

不支持。当前版本只做 Windows 版（.NET Framework 4.x，Win10/11 自带）。

自己编译

仓库里是完整的 C# 源码，只依赖 Windows 自带的 .NET Framework：

powershell -ExecutionPolicy Bypass -File build.ps1 → 生成 dist\SlotboundDropRate.exe
